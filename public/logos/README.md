# Company Logo Upload Folder

Upload your sub-company logo images here. The website loads logos automatically from this folder.

## How to upload

1. Save each logo as a **PNG file** with a transparent background (recommended).
2. Place the file in this folder: `public/logos/`
3. Use the exact filename from the table below.
4. Refresh the website — logos appear on the homepage, About page, navbar dropdown, and each company detail page.

## Required filenames

| Company | Filename | Short name |
|---------|----------|------------|
| British Way English Academy | `bwea.png` | BWEA |
| British Way International School | `bwis.png` | BWIS |
| British Campus | `british-campus.png` | BC |
| The Pharo Hotel | `pharo-hotel.png` | TPH |
| Thames College | `thames-college.png` | TC |
| Emika Productions | `emika-productions.png` | EP |
| Wisdom Cricket Academy | `wisdom-cricket-academy.png` | WCA |
| British Way Entertainment | `british-way-entertainment.png` | BWE |

## Image guidelines

- **Recommended size:** 200×200 px or larger (square works best)
- **Format:** PNG with transparent background
- **Max file size:** Under 500 KB per logo for fast loading
- **Naming:** Use lowercase letters and hyphens exactly as shown above

## Fallback behaviour

If a logo file is missing, the site displays the company initials (e.g. BWEA, BWIS) on a coloured badge until you upload the real logo.
