# Core Values Icons

Upload PNG icons for the **Core Values** section on the About page.

## How to upload

1. Save each icon as a **PNG** (transparent background recommended).
2. Place files in this folder: `public/logos/values/`
3. Use the exact filenames below.
4. Refresh the website.

## Required filenames

| Value | Filename |
|-------|----------|
| Excellence | `excellence.png` |
| Integrity | `integrity.png` |
| Innovation | `innovation.png` |
| Leadership | `leadership.png` |
| Sustainability | `sustainability.png` |

## Image guidelines

- **Recommended size:** 96×96 px or larger (square works best)
- **Format:** PNG with transparent background
- **Max file size:** Under 200 KB per icon
